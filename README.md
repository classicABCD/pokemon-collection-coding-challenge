# Pokémon Collection

Full-stack application in which trainers manage their personal Pokémon collection.

**Stack:** Java + Spring Boot (modular monolith) · React + Mantine (TypeScript) · PostgreSQL · Liquibase ·
OpenAPI (specification first) · Docker Compose

## Documentation

* [Architecture & decisions](docs/architecture.md)

## Prerequisites

| Purpose | Requirement |
|---------|-------------|
| Run the application | Docker with Docker Compose |
| Local development and tests | Java 25 (LTS), Maven 3.9, Node.js 24 (LTS), Docker (tests use Testcontainers) |
