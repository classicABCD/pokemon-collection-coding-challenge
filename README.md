# Pokémon Collection

Full-stack application in which trainers manage their personal Pokémon collection.

**Stack:** Java + Spring Boot (modular monolith) · React + Mantine (TypeScript) · PostgreSQL · Liquibase ·
OpenAPI (specification first) · Docker Compose
